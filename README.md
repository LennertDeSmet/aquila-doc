## Aquila-doc
Aquila-doc is part of the Aquila family of modern LaTeX templates.
It aims to follow and capture  the principles for science communication as laid out by [Jean-luc Doumont](https://www.principiae.be/).

### How to start using Aquila-doc
The template is packaged in a traditional, self-contained `.cls` file.
You only need to have `aquila-doc.cls` present in your folder and you can start using it by initialising your LaTeX document with `\documentclass{aquila-doc}`.
A full example of a small document that follows the principles of Aquila is given in in [`example.tex`](example.tex).
This document also showcases the basic macros necessary to write in Aquila.
